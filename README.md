# Ideatoon
Ideatoon is a platform where developers can post project ideas, browse and search other people's ideas, and like or comment on the ones that they are interested in.

## Problem
Developers often struggle with coming up with ideas for a project as well as pursuing current project ideas. Current solutions to this mainly consist of talking on broken subreddits, ChatGPT, or Discord, where chatting about their idea could be long, unhelpful, and inconvenient. I believe a project that could solve this issue could help developers in the development phase of creating their personal projects.


## Features/MVP
 - Post an idea with a title, description, tags, name, and difficulty (entry-level or senior, etc.)
 - Browse and search existing ideas
 - Like an idea
 - Comment on an idea
 - Error Handling

## Tech Stack:
 - Application Language: Python
 - Framework: Flask
 - Data Storage: SQLite
 - Frontend: HTML
 - Version Control: GitHub
 - Development Environment: Visual Studio Code

## Project Roadmap:
- Setting up the repo, virtual environment, and README
-  Making sure the Flask route works by creating a homepage that returns "Hello World" in the browser
- Creating a database file with an ideas table. The table would include columns for the title, description, tags, author name, difficulty, and timestamp
- Hardcoding a post idea where I would submit a title, description, and tag into the database and try showing the information in a browser.
- Create a page where you can search all the ideas within the database in the browser.
- Add a like button that would increase incrementally and would be saved
- Add a comment section where each comment would be stored in a list of comments in a database
- Add error handling and input validation 
- Finishing README and testing
